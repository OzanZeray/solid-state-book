### Key Historical Context

- The Debye T^3 law (1912) is verified by Parkinson 1958 with extensive metal data
- Diamond is the classic example for thermal conductivity peak — Inyushkin 2018 provides modern ultra-pure data
- Grimvall 1974 correlates Debye temperatures to melting points for the elements — a key reference table
