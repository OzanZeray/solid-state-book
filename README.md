# Experimental Data for Introductory Solid State Physics

A book presenting **real experimental data** for every topic in an introductory solid state physics course, following the structure of Kittel's *Introduction to Solid State Physics* (Chapters 1-22).

This book does not re-teach theory. It provides the experimental evidence, raw data, and landmark studies that back it up — with exact references to original papers, page numbers, and direct quotes.

**Author:** Ozan Zeray

## How This Book Was Made

1. **Research phase**: Systematic search across all 22 chapter topics using Consensus MCP (200M+ papers), Google Scholar, and arXiv
2. **Paper collection**: 70 original papers downloaded via Sci-Hub using a custom `fetch_paper.py` utility
3. **Data extraction**: PDFs read and key data tables, figures, and quotes extracted from original sources
4. **Writing**: Each chapter written in Markdown with exact references (page numbers, table numbers, direct quotes)
5. **Verification**: Every numerical value traced back to its original paper
